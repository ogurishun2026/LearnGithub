## 存放规则

- 一级目录使用主题分类，例如 `游戏开发-UE5动捕`、`AI工具`、`Blender`。
- 每个视频使用 BV 号作为独立目录，目录内统一使用 `summary.md`。
- 每份总结包含视频链接、视频信息、核心摘要、流程分析、局限性和实践建议。
- 新视频优先归入已有主题；没有合适主题时再创建新的分类目录。
