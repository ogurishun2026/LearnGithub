# 战斗待机 v1

用户要求沿用 ARDY 做战斗待机。采用徒手格斗防守：双手护住下颌、双肘弯曲、膝盖微屈、前后错开的双脚站稳，保留呼吸和小幅重心变化。沿用已验证的 Core27/28 参考人体与导出结构。

1. 用 ARDY Core8 和独立 NF4 条件缓存生成候选，保留原始 NPZ 和来源。
2. 逐帧分析、预览，选择持续保持防守的片段；以局部旋转在 SO(3) 上平滑循环，必要时固定脚接触。修改结果与原始生成分别保存。
3. 导出独立 Blender Action、BVH 和 FBX，使用零位移根骨的原地循环。重复的闭环终点用于 FBX；预览按不重复终点的帧范围播放。
4. 检查关节/权重、循环边界、足部漂移、全帧 FBX 回读，并渲染动画进行目视检查。UE 仍单独标明未实测。
5. 将动作、预览、说明和可复现脚本补充到用户已指定的 LearnGithub 仓库。

不修改走路样本、v4 基线、其他角色或旧动作。此任务没有参考图片或目标角色重定向，不启动参考图动作重建流程。
