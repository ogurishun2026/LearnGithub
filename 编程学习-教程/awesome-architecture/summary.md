# awesome-architecture 研究总结

> 仓库地址：https://github.com/study8677/awesome-architecture
> 研究日期：2026-05-30

## 一、仓库概述

awesome-architecture 是一个**专注「架构」而非「代码」的开源知识库**，收集真实热门系统的架构模板，配有一套让使用者成为更好架构师的教程。核心理念：「代码告诉计算机要做什么；架构决定这件事值不值得做、能不能做成、扛不扛得住。」864 Stars，MIT 许可证，中英文双语。

## 二、核心内容

### 2.3 架构模板（25 个）

**经典/通用系统（16 个）**：

- 视频流媒体（Netflix）：转码、CDN、自适应码率、推荐
- 实时通讯（WhatsApp、Slack）：长连接、消息时序、离线投递、群扩散
- 短链接服务（Bitly）：读多写少、缓存、301/302、分布式唯一 ID
- 支付系统（Stripe）：幂等、复式记账、对账、状态机
- 搜索引擎（Google）：倒排索引、相关性排序、召回+精排、分片
- 网约车/出行（Uber）：地理空间索引、实时位置、供需匹配、动态定价

## 三、技术特点

### 3.1 内容组织方式

- **只讲架构，不讲语法**：每个模板刻意不讨论语言/框架选择，聚焦系统设计本身
- **每个模板附真实开源项目链接**：可顺着去读源码
- **中英文双语**：在线阅读支持 HTTPS，可交互

### 3.2 配套工具

**architecture-copilot skill**（配套 Claude Code skill）：把这套知识变成能在 Claude Code / Cursor / Codex 里引导你一步步设计架构的交互式 skill。

### 3.3 三条阅读原则

1. **先问「为什么」，再看「怎么做」** — 看不到取舍就等于没看懂
2. **没有最好的架构，只有最合适的架构** — 规模、团队、成本、合规决定一切
3. **架构是会长大的** — 不要拿成熟期的架构去套 MVP

## 四、实际应用场景

### 4.1 适合的人群

| 人群 | 使用方式 |
|------|----------|
| 初学者/想转向架构思维 | 按顺序读完 tutorial，每章后再去 templates 读对应系统 |
| 正要设计新系统 | 先学 tutorial/07 方法论，再去 templates 找最接近场景的地图当起点 |
| 系统设计面试准备 | templates 每个模板都覆盖高频考点，适合系统性复习 |
| 资深工程师/架构师 | 直接看「关键决策与权衡」和「演进路线」 |

### 4.2 对 AI 时代的判断

仓库首页有一段关于「写代码正在消失」的深刻洞察：

- AI 会取代「把代码写对、写快」这件事
- 真正不会贬值的是「在动手写代码之前，先想清楚系统应该长什么样子」的能力
- 未来优秀的开发者 = **会做架构判断的人** > 会写代码的人

## 五、总结

awesome-architecture 是一个**面向 AI 时代软件工程师的架构思维训练资源库**。不同于一般的「框架教程」，它专注于系统设计本身——约束拆解、架构选型、质量属性权衡、分布式硬道理等。25 个真实系统的架构模板 + 26 章方法论，覆盖了从面试准备（系统设计面试）到生产系统设计（电商、支付、AI Agent 等）的全场景。特别值得关注的是它对 AI 时代开发者能力模型转变的前瞻性判断，以及配套的 architecture-copilot skill 可以直接用于 Claude Code 交互式学习。
